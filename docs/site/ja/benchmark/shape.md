# Shape モード vs sqip

arthash の shape モード（`CIRCLE`、`TRIANGLE`、`SQUARE`、`RECT`、`ROTATED_RECT`）は [sqip](https://github.com/axe312ger/sqip) の `primitive` プラグインと同じユースケースを狙います：画像に N 個の幾何プリミティブを山登りで配置し、結果を SVG としてレンダリング。arthash はより高速、より小さく、ブラウザ内で動作します。

## エンコード時間（JS、baseline = sqip-node）

arthash は積分画像 + SSE 増分更新を使うため、探索コストは `n` に対して亜線形です。sqip は線形 + IPC バウンド（プリミティブごとに再山登り、Go バイナリへの呼び出し）。

| 実装                           |      n=12 (倍率) |      n=24 (倍率) |       n=64 (倍率) |
| ------------------------------ | ---------------: | ---------------: | ----------------: |
| arthash · ts TRIANGLE          | 5.1 ms (**56×**) | 7.9 ms (**56×**) | 15.2 ms (**67×**) |
| arthash · ts CIRCLE            |     5.3 ms (54×) |     7.2 ms (62×) |     15.5 ms (66×) |
| sqip · primitive-triangle @0.3 |           284 ms |           446 ms |           1015 ms |

差は **`n` の増加とともに広がります**—n=12 で 56× 高速、n=64 で 67× 高速。

## 出力サイズ

| 実装                           |        n=12 (倍率) |         n=24 (倍率) |         n=64 (倍率) |
| ------------------------------ | -----------------: | ------------------: | ------------------: |
| arthash · ts CIRCLE            | 53 B (**16× 小**) | 102 B (**15× 小**) | 267 B (**14× 小**) |
| arthash · ts TRIANGLE          |     77 B (11× 小) |     150 B (10× 小) |      395 B (9× 小) |
| sqip · primitive-triangle @0.3 |              842 B |              1482 B |              3650 B |

sqip は完全な SVG 文字列を出力し、各プリミティブに `<polygon points="..." fill="..." ... />` マークアップが付きます。arthash は幾何をマークアップオーバーヘッドのないパックビットストリームに格納し、レンダリング時にだけ SVG に変換します。

## 各々の得意分野

|                        | sqip (`primitive`)        | arthash (shape モード)     |
| ---------------------- | ------------------------- | -------------------------- |
| ランタイム             | Node + Go 子プロセス      | 純 wasm（ブラウザ / Node） |
| デプロイ形態           | **ビルド時のみ**          | ビルド時またはリクエスト時 |
| 出力                   | 直接 SVG 文字列           | パックハッシュ → 必要時 SVG |
| 出力サイズ             | 800 B – 4 kB              | 50 B – 400 B               |
| n=64 エンコード時間    | ~1 s                      | ~15 ms                     |
| 形状ごとの色ビット幅   | 24 (truecolour) + alpha   | 16 (RGB-565) または 4 (パレット) |

sqip は両端を制御できず、arthash 対応のデコーダなしで直接 SVG 文字列が欲しい場合に向いています。arthash は両端を制御でき、より小さいペイロードまたはブラウザサイドのエンコードが欲しい場合に勝ちます。

## 比較条件のメモ

- sqip は `primitive-triangle` プラグイン、デフォルトの `progressive: 0.3` で実行—プラグイン公式サンプルの設定と一致。
- arthash の数値はデフォルトの `Codec::triangle(n)` / `Codec::circle(n)`（RGB-565 カラー、3 bit alpha）。パレットモードに切り替えるとさらに小さくなり、RGB-888 に切り替えると形状ごとに ~8 bit 大きくなります。
- すべての sqip / arthash 出力は同じ `viewBox` サイズでレンダリングされ、ディスクサイズの直接比較が可能になっています。
