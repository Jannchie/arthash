# 画質比較

オリジナル画像との PSNR、長辺 256 px 出力で計算、標準テストコーパスで平均。高いほど良い；+3 dB ≈ 信号対雑音比が倍。

## 画質テーブル（PSNR 降順）

| 出力                  |  バイト |    PSNR |
| --------------------- | ------: | ------: |
| sqip · 12 プリミティブ SVG | ~1100 B | 24.4 dB |
| arthash · DCT         |    17 B | 23.3 dB |
| thumbhash             |    17 B | 22.9 dB |
| arthash · TRIANGLE 12 |    77 B | 21.4 dB |
| arthash · CIRCLE 12   |    53 B | 20.7 dB |

## 主な結論

- **17 B の予算**では、arthash DCT が thumbhash より **+0.4 dB PSNR** 高い—無料、エンコーダーのチューニング不要。
- **arthash TRIANGLE 12** は 77 B で 21.4 dB に到達。sqip の 24.4 dB の方が良いが、**14× のバイトコスト**（~1100 B）。これは 3 dB の画質ドロップで 1/14 のサイズ削減と引き換え—プレースホルダーには通常良いトレードオフです。
- **arthash CIRCLE 12** は shape モード中で最小の出力（53 B）で、それでも 20.7 dB に達する—3× のバイト予算の thumbhash のぼやけた出力と競合しつつ、ぼやけたラスターではなく鋭い SVG プリミティブを使用。

## PSNR が重要なときと重要でないとき

PSNR は便利な客観指標ですが、プレースホルダーは本質的に知覚問題です。"一目見て元の画像のように見えるか"の実際のランキングはおおむね：

1. **arthash TRIANGLE 24+** — 形状が認識可能、本物の色再現性。
2. **arthash DCT** — 強い色と構造、滑らかなぼけ。
3. **thumbhash** — arthash DCT と同じアイデア、量子化がやや弱い。
4. **arthash CIRCLE 12** — 特徴的なスタイル、低忠実度。
5. **sqip プリミティブ** — PSNR は高いが大きい；バイトが豊富なときのみ競争力。

ブランド一貫のプレースホルダーでは、パレットモードは生の PSNR では低いスコアですが、色の分布がデザインシステムに一致するため主観的にはより高いスコアを得ます。

## 方法論

- **コーパス**: 24 枚のリファレンス画像（ポートレート、風景、製品ショット、UI スクリーンショット）。[JS クロス実装 bench](https://github.com/Jannchie/arthash/tree/main/bench/js-cross) と同じセット。
- **デコードサイズ**: 長辺 = 256 px。ネイティブが小さいサイズで出力する実装（特に thumbhash のデフォルト ~32 px）は、PSNR 計算前に双線形で 256 px にアップサンプリング。
- **色空間**: PSNR はガンマデコード後の sRGB で計算。リニアライトまたは Oklab に切り替えるとすべての数値が ~0.5 dB 上がりますが、ランキングは変わりません。
